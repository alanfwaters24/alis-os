# ALIS app icons

The ecosystem apps' own icons, installed as named icons (`alis-<module>`) so
ALIS OS launchers match the phone apps. Copied from the apps' repos — if an
app's icon changes there, copy it here again (256 px, rounded like the rest).

| File | From |
|---|---|
| alis-dashboard.png | arch-store `icons/alis.png` (ALIS NEST) |
| alis-dose.png | arch-store `icons/dose.png` (same as dose `icon-512.png`) |
| alis-arch.png | arch-store `icons/store-512.png` (ALIS App Store) |
| alis-vault.png | arch-store `icons/vault.png` (corners rounded here) |
| alis-stall.svg | alis-stall `public/favicon.svg` |
| alis-assistant.svg | alis-assistant `app/src/main/res/drawable/ic_launcher.xml` (redrawn as SVG, corners rounded) |
